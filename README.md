# Brad Matera Interactive Systems Lab

A production frontend showcase with 25 distinct experiences: Babylon.js 3D systems, realistic simulations, complete website concepts, engineering tools, and six playable 3D browser games.

## Live site

https://bradleymatera.github.io/GameTesting/

## What is included

- 1 cinematic 3D command center
- 6 distinct systems simulations
- 5 complete responsive website demonstrations
- 7 engineering and design tools
- 6 actual Babylon.js 3D games
- original repository-owned SVG artwork
- procedural 3D models for agents, server racks, vehicles, buildings, equipment, creatures, terrain, towers, and environments
- desktop and mobile gallery navigation
- truthful runtime telemetry for Babylon.js scenes

## Assets

The illustrations under `assets/` were created specifically for this repository. The 3D scenes use original procedural composite models built from Babylon.js geometry so the project does not depend on hotlinked or unexplained third-party game assets. See `assets/asset-manifest.md`.
